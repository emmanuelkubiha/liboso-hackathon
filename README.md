## LIBOSO SERVICE - Plateforme Africaine

**LIBOSO SERVICE** est une plateforme digitale innovante pour les services urbains en Afrique.

### Contributeur
- **Développeur**: Emmanuel Kubiha
- **Email**: emmanuelkubiha@gmail.com
- **Date de déploiement**: 16 mai 2026
- **Version**: 0.1.0 (MVP Production Ready)

### Stack Technologique
- Next.js 15 + React 19 + TypeScript
- Tailwind CSS 4 + Framer Motion
- Lucide React Icons
- Context API (i18n FR/EN + Dark Mode)

### Caractéristiques
- 8 pages principales + Dashboard admin
- 10 services urbains
- Système de réservation 5-étapes
- 6 méthodes de paiement
- Réseau 5 pays africains
- Animations et responsive design complet

### Démarrage Rapide

```bash
npm install
npm run dev
# → http://localhost:3000
```

### Pages
- `/` - Homepage
- `/services` - Services
- `/about` - À propos
- `/transborder` - Réseau régional
- `/impact` - Impact social
- `/team` - Équipe
- `/contact` - Contact
- `/booking` - Réservation
- `/dashboard` - Admin

### Déploiement
```bash
npm run build
vercel --prod
```
